КАЛЬКУЛЯТОР ЭКРАНА v1.4 — PWA

Загрузите в корень публичного GitHub-репозитория все файлы:
index.html
manifest.webmanifest
service-worker.js
icon-192.png
icon-512.png

GitHub Pages:
Settings → Pages → Deploy from a branch → main → / (root) → Save

После публикации откройте сайт на Android в Chrome и выберите
«Установить приложение» или «Добавить на главный экран».

После первого открытия приложение сможет работать офлайн.


Версия 1.2:
- показывает общее количество пикселей экрана;
- показывает небольшую таблицу ограничений на ОДИН Ethernet-порт для популярных режимов;
- для каждого режима автоматически считает, сколько портов нужно текущему экрану;
- основная строка для MCTRL300: 8 bit / 60 Hz / 650 000 px на порт.


Версия 1.3:
- необходимое разрешение экрана всегда показывается только целыми пикселями;
- теоретическое значение округляется до ближайшего целого пикселя и помечается знаком ≈;
- например 739,6 × 416 px теперь отображается как ≈ 740 × 416 px.


Версия 1.4:
- добавлен режим «Свободный размер экрана»;
- в этом режиме X и Y задаются независимо и не подгоняются под 16:9;
- заданное соотношение остаётся эталоном для сравнения;
- показывается фактическое соотношение и отклонение в процентах;
- показываются два варианта выхода на целевое соотношение: сохранить ширину или сохранить высоту;
- для каждого варианта показывается необходимое изменение размера в сантиметрах.
