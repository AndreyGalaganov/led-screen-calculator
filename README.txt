index.html

GitHub Pages:
Settings → Pages → Deploy from a branch → main → / (root) → Save

После публикации откройте сайт на Android в Chrome и выберите
«Установить приложение» или «Добавить на главный экран».

После первого открытия приложение сможет работать офлайн.


Версия 1.2:
- показывает общее количество пикселей экрана;
- показывает небольшую таблицу ограничений на ОДИН Ethernet-порт для популярных режимов;
- для каждого режима автоматически считает, сколько портов нужно текущему экрану;
- основная строка для MCTRL300: 8 bit / 60 Hz / 650 000 px на порт.


Версия 1.3:
- необходимое разрешение экрана всегда показывается только целыми пикселями;
- теоретическое значение округляется до ближайшего целого пикселя и помечается знаком ≈;
- например 739,6 × 416 px теперь отображается как ≈ 740 × 416 px.


Версия 1.4:
- добавлен режим «Свободный размер экрана»;
- в этом режиме X и Y задаются независимо и не подгоняются под 16:9;
- заданное соотношение остаётся эталоном для сравнения;
- показывается фактическое соотношение и отклонение в процентах;
- показываются два варианта выхода на целевое соотношение: сохранить ширину или сохранить высоту;
- для каждого варианта показывается необходимое изменение размера в сантиметрах.


Версия 1.5:
- в свободном размере добавлен выбор стороны-ориентира X или Y;
- если ориентир X, X считается неизменяемым и показывается только требуемый Y;
- если ориентир Y, Y считается неизменяемым и показывается только требуемый X;
- убраны одновременно показываемые два варианта и процент отклонения из свободного режима;
- вместо этого выводится одно понятное действие: увеличить или уменьшить вторую сторону на нужное количество сантиметров.


Версия 1.6:
- формулировки в свободном режиме сделаны нейтральными;
- вместо «Нужно увеличить/уменьшить» показываются эталонное значение, фактическое значение и разница;
- пример: «Y по эталону: 2,25 м», «Фактический Y: 2,5 м», «Разница Y: +25 см».


Версия 1.7:
- итоговый информационный блок открывается на весь экран по нажатию мышкой или пальцем;
- полноэкранный режим сделан специально для удобного просмотра и скриншота;
- в полноэкранном виде показываются итог расчёта, общее количество пикселей и таблица ограничений на 1 Ethernet-порт;
- закрытие: кнопка × или клавиша Esc.


Версия 1.8:
- в полноэкранный информационный раздел добавлены параметры одного кабинета;
- показывается физический размер кабинета по X × Y в сантиметрах;
- показывается разрешение кабинета по X × Y в пикселях;
- эти данные отображаются только в увеличенном итоговом окне и удобно попадают в скриншот.
