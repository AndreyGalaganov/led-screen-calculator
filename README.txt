КАЛЬКУЛЯТОР ЭКРАНА v1.2 — PWA

Загрузите в корень публичного GitHub-репозитория все файлы:
index.html
manifest.webmanifest
service-worker.js
icon-192.png
icon-512.png

GitHub Pages:
Settings → Pages → Deploy from a branch → main → / (root) → Save

После публикации откройте сайт на Android в Chrome и выберите
«Установить приложение» или «Добавить на главный экран».

После первого открытия приложение сможет работать офлайн.


Версия 1.2:
- показывает общее количество пикселей экрана;
- показывает небольшую таблицу ограничений на ОДИН Ethernet-порт для популярных режимов;
- для каждого режима автоматически считает, сколько портов нужно текущему экрану;
- основная строка для MCTRL300: 8 bit / 60 Hz / 650 000 px на порт.
